# SpaceU87_Nov2024 Pipeline

This folder contains a set of scripts used to process UMI-based RNA-seq data from U87 and U87+THP-1 spheroids (Nov 2024).

The `archive/` folder contains older scripts written for **CogentAP**.  
I initially attempted to use CogentAP for UMI handling, but encountered multiple issues, so the final pipeline relies entirely on **UMI-tools** for UMI extraction and deduplication.

## Overview of Pipeline

### 1. `00_run_umi_extract.sh`
Extracts UMIs from raw FASTQ files using: `umi_tools extract`

- Inputs: `*_R1_001.fastq.gz`, `*_R2_001.fastq.gz`  
- Outputs: UMI-extracted FASTQs with UMIs moved into read headers  
- Logs: `_extract.log` (generated by UMI-tools)

---

### 2. `01_run_trimmomatic.sh`
Runs **Trimmomatic** on the UMI-extracted FASTQs.

- Inputs: UMI-processed FASTQs  
- Outputs: trimmed FASTQs (e.g. in `trimmed/`)  
- Used primarily to remove fixed leading bases (e.g., HEADCROP)

---

### 3. `03_run_STAR_GeneCounts.sh`
Runs **STAR** to align reads to the genome and produce sorted BAM files.

- Inputs:  
  - R1: UMI-extracted FASTQ  
  - R2: trimmed FASTQ  
- Outputs:  
  - `${sample}Aligned.sortedByCoord.out.bam`  
  - STAR logs and junction files

---

### 4. `04_run_samtools_index.sh`
Indexes STAR BAM files using **samtools index**.

- Input: STAR-aligned BAM  
- Output: `${sample}.bam.bai` index file  
- Needed for QC and for some downstream tools

---

### 5. `05_run_umi_dedup.sh`
Deduplicates aligned reads using **UMI-tools dedup**.

- Input: STAR BAM  
- Output: `${sample}_deduplicated.bam`  
- Stats written to:
  - `deduplicated_per_umi.tsv`
  - `deduplicated_per_umi_per_position.tsv`
  - `deduplicated_edit_distance.tsv`
  - etc.

This step removes PCR duplicates using UMI-aware grouping.

---

### 6. `06_run_featurecounts.sh`
Generates gene-level counts using **featureCounts**.

- Input: deduplicated BAM  
- Output: `${sample}_counts.txt` in `featureCounts/`  
- Uses RefSeq or GENCODE GTF annotation (see script for exact path)

---

### 7. `07_umi_qc_stats.Rmd`
This document summarizes quality-control analyses for the sequencing dataset, focusing on STAR alignment metrics and UMI-tools deduplication performance.


## File Reference

- `file_prefixes.txt` — List of sample prefixes used to submit array jobs  
- `logs/` — Contains SGE log files for submitted jobs  
- `archive/` — Contains CogentAP-based scripts (not used in final workflow)  
- `featureCounts/` — Final expression matrices per sample
